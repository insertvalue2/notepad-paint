# notepad-paint (메모장 그림)

브라우저에서 바로 쓰는 **메모장 + 그림판 + 코드 편집기** 한 벌짜리 앱입니다. 설치나 빌드 없이 `index.html` 하나로 동작하고, 서버로 아무것도 보내지 않습니다.

- 사이트: https://insertvalue2.github.io/notepad-paint/
- 실행: 저장소의 `index.html`을 브라우저로 열면 됩니다. (글꼴 Noto Sans KR만 Google Fonts에서 받아 오며, 없으면 시스템 글꼴을 씁니다.)
- 권장 브라우저: 최신 Chrome / Edge 계열. 찾기 표시와 코드 블록 색칠에 CSS Highlight 기능을 사용합니다.

## 한눈에 보기

위쪽 탭 줄에서 **메모장**, **그림판**, **코드** 탭을 여러 개 만들어 오가며 쓸 수 있습니다. `+` 버튼이나 `Alt+Shift+1/2/3`으로 새 탭을 만들고, 탭을 더블클릭하면 이름을 바꿀 수 있습니다. 탭이 많으면 줄이 스크롤되고 오른쪽 목록 버튼으로 골라 갈 수 있습니다. 라이트/다크 테마를 전환할 수 있고, 휴대폰 화면 폭에도 맞춰집니다.

| 탭 | 용도 |
| --- | --- |
| 메모장 | 서식이 있는 메모. 제목, 목록, 체크리스트, 색, 이미지, 코드 블록 |
| 그림판 | 펜, 도형, 텍스트, 사진 배치, UML 클래스 다이어그램용 상자와 화살표 |
| 코드 | Java/JSON 작성·붙여넣기, 클래스 다이어그램과 실행 흐름 미리보기, JSON 도구 |

## 메모장 탭

- 서식: 굵게, 밑줄, 취소선, 글자 크기, 글자색, 정렬, 구분선. (기울임은 쓰지 않습니다.)
- 목록: 글머리, 번호, 체크리스트. 줄 맨 앞에서 `- `, `1. `, `[] `를 치면 자동으로 목록이 되고, 빈 줄에 `---`와 Enter로 구분선을 넣습니다.
- 글을 드래그하면 바로 위에 빠른 서식 막대(글자 크기 A−/A+, 검정·빨강·파랑과 팔레트, 굵게)가 나타납니다. 글자 크기는 `Alt+↑` / `Alt+↓`로도 바꿀 수 있고, 10부터 52까지 한 단계씩 바뀝니다. 크기가 섞인 글을 골라도 조각마다 제 크기에서 한 단계씩 움직이고, 아무것도 고르지 않고 누르면 커서가 있는 줄 전체가 바뀝니다. (`Alt + =`는 윈도우 한글 입력기가 전각/반각 전환으로 먼저 가로채므로 쓰지 않습니다.)
- 글 중간에서 `Shift+Enter`를 누르면 줄을 나누지 않고 커서만 다음 줄 맨 앞으로 갑니다. 마지막 줄이면 아래에 빈 줄이 생깁니다.
- 이미지: 붙여넣기나 끌어놓기로 넣고, 25% / 50% / 꽉 차게 버튼이나 모서리 끌기로 크기를 조절합니다. 이미지를 클릭하면 나오는 **저장** 버튼으로 원본 형식(png/jpg 등) 파일로 내려받을 수 있습니다.
- 찾기/바꾸기(`Ctrl+F`), 확대·축소(`Ctrl+휠`), 줄·열·글자 수 표시.
- 내보내기: **MD**(이미지를 포함한 단일 .md), **PDF**(A4, 바로 열리는 .pdf), 서식 포함 .html, 일반 .txt.

### 코드 블록

메모에 코드를 넣으면 회색 코드 영역(코드 블록)으로 보여 주고, Java·JSON은 색을 입혀 줍니다. 다른 언어는 범용 규칙으로 칠합니다.

#### 만드는 법

| 방법 | 설명 |
| --- | --- |
| 코드 붙여넣기 | 여러 줄 코드를 붙여넣으면 자동으로 코드 블록이 됩니다. VS Code·IDE·웹의 코드 블록에서 복사한 것은 확실히 인식하고, 일반 텍스트는 코드처럼 보일 때만 바뀝니다. |
| `Alt+C` 또는 서식 막대의 `</>` 버튼 | 선택한 줄(또는 커서가 있는 줄)을 코드 블록으로 묶습니다. 코드 블록 안에서 다시 누르면 일반 문단으로 돌아옵니다. |
| 빈 줄에서 백틱 세 번 (```` ``` ````) | 세 번째 백틱을 치는 순간 바로 코드 블록이 됩니다. |

`Ctrl+Shift+V`로 붙여넣으면 코드 블록으로 바꾸지 않고 일반 글로 넣습니다. 목록이나 제목 안에서도 자동 변환하지 않습니다.

번호 목록 항목에서 `Alt+C`를 누르면 그 자리에서 목록이 나뉘고 사이에 코드 블록이 들어갑니다. 코드 블록 아래의 번호 목록은 1부터 다시 세지 않고 위 목록의 번호를 이어 받으며, 사이의 코드 블록을 지우면 두 목록이 하나로 합쳐집니다.

#### 코드 블록 안에서

- `Enter`: 앞 줄의 들여쓰기를 이어 갑니다. `{` `[` `(` 뒤에서는 한 단계 더 들여씁니다.
- 끝의 빈 줄에서 `Enter`를 한 번 더 누르면 블록 밖으로 나갑니다.
- `Tab`: 다음 4칸 위치까지 공백을 채웁니다. 줄 맨 앞에서 `}` `]`를 치면 들여쓰기가 한 단계 줄어듭니다.
- `Ctrl+A`: 먼저 그 블록의 글만 선택하고, 한 번 더 누르면 문서 전체를 선택합니다.
- 블록 맨 앞에서 `Backspace`: 일반 문단으로 되돌립니다. 빈 블록이면 블록을 지웁니다.
- 블록 안에서는 굵게, 글자 크기, 목록 같은 서식을 쓸 수 없습니다.

#### 삭제와 되돌리기

- 마우스를 올리거나 커서가 블록 안에 있으면 오른쪽 위에 `삭제` 버튼이 나타납니다. 코드가 길어 스크롤해도 화면에 보이는 위쪽에 붙어 있습니다.
- 삭제, `Alt+C` 변환, 백틱 변환은 `Ctrl+Z`로 되돌리고 `Ctrl+Y`(`Ctrl+Shift+Z`)로 다시 실행할 수 있습니다. 직후 문서가 그대로일 때만 쓰이고, 그 사이에 글을 고쳤다면 브라우저 기본 되돌리기를 따릅니다.

#### 저장과 내보내기

- 메모를 닫았다 열어도 코드 블록이 유지됩니다.
- **MD**: 코드 펜스(```` ``` ````)로 내보냅니다. 코드 안의 연속된 빈 줄도 그대로 보존합니다.
- **PDF**, **HTML**: 코드 영역 스타일이 반영됩니다(PDF는 색 없이 나옵니다).

## 그림판 탭

- 도구: 선택, 펜, 텍스트, 지우개, 획 지우개, 직선, 사각형, 원, 메모 상자.
- UML: 클래스 상자(이름/속성/메소드)와 상속, 구현, 연관, 의존, 집합, 합성 화살표. 선에 라벨(`<<use>>`, `1..*` 등)을 달 수 있습니다.
- 사진 열기, 붙여넣기, 끌어놓기와 크기 조절, 격자 맞춤, 확대·축소, 끝없는 캔버스(화면 밖에 그림이 있으면 돌아가기 버튼 표시).
- 실행 취소/다시 실행, PNG 내보내기, PNG를 클립보드로 복사.

## 코드 탭

- 줄 번호와 색칠이 있는 편집기. 파일 열기·끌어놓기, 저장, 전체 복사, 찾기/바꾸기, 들여쓰기(공백 2/4/8 또는 탭), 줄 끝(LF/CRLF), 글자 크기, 자동 줄바꿈, 괄호 자동 닫기, `Ctrl+/` 주석 토글, `Ctrl+D` 줄 복제를 지원합니다.
- **Java**: 오른쪽 미리보기에서 *클래스 구조*(UML 클래스 다이어그램)와 *실행 흐름*(메소드 호출 시퀀스 다이어그램)을 볼 수 있습니다. 관계(상속, 구현, 연관, 집합, 합성, 의존) 표시를 켜고 끌 수 있고, getter 숨김, 이름만 보기, 집중 보기, 범례를 지원합니다. 다이어그램은 복사하거나 **그림판으로 보내** 도형으로 고칠 수 있습니다.
- **JSON**: 오류 위치 안내, 트리 보기(펼치기/접기), 정리·한 줄로·키 정렬, JSON에서 Java 클래스 만들기(getter/setter, Lombok, record).
- 예제 코드를 골라 넣어 볼 수 있습니다.

## 저장과 불러오기

- 작업 내용은 브라우저에 자동 저장되어 새로고침이나 재방문 후에도 이어집니다. (저장 공간이 모자라면 사진은 임시 저장에서 빠진다고 알려 줍니다.)
- **프로젝트 저장**(`Ctrl+Shift+S`)으로 모든 탭을 `.npaint` 파일 하나에 담고, 열기로 다시 불러올 수 있습니다.
- 텍스트, 코드, 이미지 파일을 열거나 화면에 끌어놓으면 알맞은 탭으로 열립니다.

## 주요 단축키

탭마다 달라서 화면 위쪽의 키보드 아이콘에서 지금 탭의 단축키를 볼 수 있습니다.

| 범위 | 키 |
| --- | --- |
| 공통 | `Ctrl+S` 저장, `Ctrl+Z` 실행 취소, `Ctrl+F` 찾기, `Alt+Shift+1/2/3` 새 메모장/그림판/코드 |
| 메모장 | `Alt+↑` / `Alt+↓` 글자 크게/작게, `Shift+Enter` 다음 줄로, `Alt+L` 글머리, `Alt+N` 번호, `Alt+T` 체크리스트, `Alt+H` 구분선, `Alt+C` 코드 블록, `Ctrl+B` 굵게 |
| 그림판 | `Alt+1~4` 선택/펜/텍스트/지우개, `Ctrl+C/V` 복사/붙여넣기, `Ctrl+D` 복제, `Delete` 삭제 |
| 코드 | `Tab` 들여쓰기, `Ctrl+/` 주석, `Ctrl+D` 줄 복제, `Ctrl+Enter` 미리보기 실행 |


## 구조

- 외부 라이브러리 없이 순수 HTML, CSS, JavaScript로 만든 단일 파일(`index.html`)입니다.
- 모든 처리는 브라우저 안에서 이루어지며 데이터는 브라우저 저장소(IndexedDB, 보조로 `localStorage`)와 사용자가 저장한 파일에만 남습니다. 임시 저장은 비동기로 이루어져 사진이 든 메모에서도 타자가 멈칫하지 않습니다.
- GitHub Pages로 제공됩니다 (`main` 브랜치의 `index.html`).
